# Daykeep Cloud

:::tip
If you want to use Daykeep without running your own servers, the hosted cloud option is the fastest way to start.
:::

[Daykeep Cloud](https://cloud.daykeep.app) is the fully managed version of Daykeep operated by the core team. It handles hosting, updates, monitoring, and backups for you, so you can focus on saving content instead of maintaining infrastructure.

### Get started

1. Visit [cloud.daykeep.app](https://cloud.daykeep.app) and create an account.
2. Follow the onboarding flow to create your workspace.
3. Install the browser extension or mobile apps from the [quick sharing page](../04-using-karakeep/quick-sharing.md) and start saving links immediately.
